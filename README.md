# faustinopalma.github.io

Personal site for Faustino Palma. The site is static, bilingual, and published with GitHub Pages.

## Local preview

```powershell
python -m http.server 4173
```

Open `http://localhost:4173/`.

## Publication

The Pages workflow publishes the repository root. The `.private/` directory is excluded from Git and is never part of the deployment artifact.
